### Project Description

InverseLux is an **aggressively perverse anti-ergonomic menace**. Rather than being a helpful optical assistant, it enforces the absolute worst display conditions for your eyes at any given moment:

* **3:00 AM Pitch-Black Room:** Burns your retinas with pure, unyielding `#FFFFFF` sunlight at 140% brightness.
* **Broad Daylight / Direct Fluorescent Tubes:** Snaps into an impenetrable obsidian dark mode with crushed contrast so you can't read a single line of text.

---

### The Problem (that doesn't exist)

Modern operating systems coddle users with adaptive brightness, True Tone, Night Shift, and auto dark mode to prevent "eye fatigue." This artificial biological comfort has made human eyes weak, soft, and unaccustomed to real optical adversity.

### The Solution (that nobody asked for)

InverseLux restores evolutionary resilience through an in-browser photometric surveillance engine. Using real-time canvas pixel sampling via your webcam, it strictly enforces the **exact inverse** of what your retinas require. The moment you seek sanctuary in darkness, the engine triggers a 140% brightness flashbang; step into broad daylight, and it plunges the screen into a pitch-black blackout void.

## Technical Details

### Technologies & Components Used

**For Software:**
- **Languages:** JavaScript (ES6+), CSS3, HTML5
- **APIs:** WebRTC (`navigator.mediaDevices.getUserMedia`), HTML5 Canvas API, Web Audio API
- **Frameworks & Environments:** Chromium Extension Architecture (Manifest V3)
- **Tools:** Google Chrome DevTools, VS Code

**For Hardware:**
- **Main Components:** Integrated Laptop Webcam or USB Webcam (used as an adversarial optical lux meter)
- **Specifications:** Minimum 64x64 video capture stream
- **Tools Required:** A hand, thumb, or dark cloth (for inducing simulated nighttime and triggering flashbangs)

## Implementation

### Installation

1. Clone or download this repository:

```bash
git clone https://github.com/Pridhvin/InverseLux.git
cd InverseLux
```

2. Open Google Chrome and navigate to:

```text
chrome://extensions
```

3. Enable **Developer mode** via the toggle switch in the top-right corner.
4. Click **Load unpacked** in the top-left and select the `InverseLux` project directory.

### Quick Console Drop-In (No Extension Required)

You can also run InverseLux instantly on any webpage via your browser's Developer Tools Console:
1. Open the Developer Tools console (`F12` or `Ctrl+Shift+I` / `Cmd+Option+I`).
2. Paste and run the drop-in script from [`injected.js`](file:///c:/Users/pridh/Projects/InverseLux/injected.js) (also in [`src/injected.js`](file:///c:/Users/pridh/Projects/InverseLux/src/injected.js)).
3. Allow camera access when prompted and enjoy maximum circadian hostility.
